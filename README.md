# YouTube Clone (HTML/CSS Practice Project)

This project was built as part of an HTML & CSS course to practice layout, flexbox, and responsive design.

It is a static clone focused on UI replication (no backend functionality).

Tech used:
- HTML5
- CSS3 (Flexbox, Grid)
- Tiny bit of JavaScript

What I practiced:
- Responsive layout
- Component structure
- Clean folder organization
- Linking images, fonts and styles
- Writing clean code
