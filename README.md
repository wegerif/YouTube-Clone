# YouTube Clone (HTML/CSS Practice Project)

This project was built to practice HTML & CSS, with the intention of learning things like layout, flexbox, and responsive design.

It is a static clone focused on UI replication, with very limited functionality, although all the video's are real and clickable.

Tech used:
- HTML5
- CSS3 (Flexbox, Grid)
- Tiny bit of JavaScript

What I practiced:
- Responsive layout
- Component structure
- Clean folder organization
- Linking images, fonts and styles
- Writing clean code
- Visual UX Design

I've originally followed a [course](https://www.youtube.com/watch?v=G3e-cpL7ofc){:target="_blank"} by @SuperSimpleDev, to get started. He shows the page in the default light-mode. Personally I am a big fan of dark-mode, hence why I developed the project to use that, which helped me further understand what I'm doing.
I also went out of my way to create something unique after following the basics, figuring out how to make things responsive, look and feel different or just have fun with elements.
